# @brahmaputra/ws-react

React hooks for the Brahmaputra WebSocket gateway: `BrahmaputraProvider`, `useLatestByKey`, `useRecentRecords`, `useSubscription`, `usePublish`, `useConnectionState`.

Usage, authentication, the price-feed guide and the test suites are in [../README.md](../README.md).

```bash
npm install
npm run build   # tsc -> dist/
```
