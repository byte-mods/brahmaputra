# @brahmaputra/ws-angular

Angular providers, signals and observables for the Brahmaputra WebSocket gateway: `provideBrahmaputra`, `injectLatestByKey`, `injectRecentRecords`, `injectPublish`, `injectConnectionState`, and `records$` / `latestByKey$` / `connectionState$`. There are no decorators, so AOT, JIT and zoneless apps all work.

Usage, authentication, the price-feed guide and the test suites are in [../README.md](../README.md).

```bash
npm install
npm run build   # tsc -> dist/
```
