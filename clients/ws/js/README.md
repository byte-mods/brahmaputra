# @brahmaputra/ws-client

The core client for the Brahmaputra WebSocket gateway, for browsers, React Native and Node 22+. No dependencies. Publish with acknowledgements, subscribe to live topics with snapshots, reconnect with backoff, and use `latestByKey` / `recentRecords` stores (plus the Svelte adapter at `@brahmaputra/ws-client/svelte`).

Usage, authentication, the price-feed guide and the test suites are in [../README.md](../README.md).

```bash
npm install
npm run build   # tsc -> dist/
```
