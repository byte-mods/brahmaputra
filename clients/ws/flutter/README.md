# brahmaputra_ws_flutter

Flutter widgets for the Brahmaputra WebSocket gateway: `BrahmaputraScope`, `ConnectionStatusBuilder`, `LatestByKeyBuilder` and `RecentRecordsBuilder`. [example/lib/main.dart](example/lib/main.dart) is a complete stock-ticker app.

The guide is in [../README.md](../README.md).

```bash
flutter pub get
../test.sh flutter  # widget tests against a real gateway
```
