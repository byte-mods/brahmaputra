# @brahmaputra/ws-vue

Vue 3 plugin and composables for the Brahmaputra WebSocket gateway: `createBrahmaputra`, `useLatestByKey`, `useRecentRecords`, `usePublish`, `useConnectionState`. Topics and options may be refs or getters.

Usage, authentication, the price-feed guide and the test suites are in [../README.md](../README.md).

```bash
npm install
npm run build   # tsc -> dist/
```
